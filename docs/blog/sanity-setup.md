# Previous Sanity setup

Sanity Studio and the Sanity delivery client have been removed from this application. Use [the blog integration guide](./dev-guide.md) for the current setup and [the client guide](./client-guide.md) for editing in the Bea Vita app.

The original published content was exported for migration and rollback. Removing the application integration does not delete that external dataset. The migrated blog uses workspace photo storage and keeps the existing `/blog` addresses, dates, bylines and public design.
